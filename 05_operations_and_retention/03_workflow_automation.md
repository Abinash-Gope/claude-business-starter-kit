# 🤖 3. Automate Repetitive Tasks

## Why Task Automation Frees You for High-Value Work

Automating administrative and repetitive tasks reduces burnout and frees your time for revenue-generating activities.

---

## 🛠️ Automation Recipe Collection

| Process | Trigger | Tool | Automation Logic |
|---|---|---|---|
| Lead Capture → CRM | Form Submission | Make.com / Zapier | Create Contact, assign to pipeline stage |
| Pipeline Deal Stage Move | Updated Deal | CRM webhook | Assign internal task, set reminder |
| Invoice After Proposal Accepted | Payment Received | Stripe + Slack | Send welcome email, assign onboarding |
| Client Health Score Change | Weekly Metric Export | Python script | Flag churn risk, notify manager |
| Post-NPS Survey Trigger | Quarter End | Automated email | Send NPS survey, compile results |

---

## 📋 Workflow Automation Checklist

- [ ] Identify 3+ high-volume repetitive tasks
- [ ] Map manual steps and bottlenecks
- [ ] Select automation tool (Zapier, Make, n8n, custom script)
- [ ] Build first automation end-to-end
- [ ] Monitor errors for 2 weeks
- [ ] Document SOP for future replication
