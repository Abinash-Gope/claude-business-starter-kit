# Claude Business Starter Kit - GitHub Ready

## One-Command Installation

```bash
bash <(curl -sSL https://raw.githubusercontent.com/your-username/claude-business-starter-kit/main/install-business-starter-kit.sh)
```

Or clone and run locally:

```bash
git clone https://github.com/your-username/claude-business-starter-kit.git
cd claude-business-starter-kit
bash install-business-starter-kit.sh
```

## 🛠️ Customization

### Change Your Business Name & Details

Edit `config/business_config.json` (create this file) with your specifics:

```json
{
  "business_name": "Your Business Name",
  "industry": "Your Industry",
  "target_niche": "Your Niche",
  "primary_icp": "Your Target Persona",
  "pricing_tier_growth": "$3,500/mo",
  "tech_stack": {
    "crm": "HubSpot",
    "outreach": "Instantly",
    "automation": "Make.com",
    "website": "Webflow"
  }
}
```

Or simply replace placeholder text like `[Your Business Name]` in the markdown files.
